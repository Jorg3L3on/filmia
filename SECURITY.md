# Seguridad

Filmia es un proyecto personal. Si encuentras una vulnerabilidad, **no abras un issue
público**: repórtala en privado con
[GitHub Security Advisories](https://github.com/Jorg3L3on/filmia/security/advisories/new).

Incluye qué encontraste, cómo reproducirlo y el impacto que ves. Respondo en cuanto pueda;
no hay programa de recompensas.

Solo se da soporte a la versión desplegada desde `main`.
